# Planify

Aplicación escolar para organizar actividades personales. Usa Flask para el servidor y MySQL para guardar cuentas, actividades, preferencias e historial.

Cada persona instala su propia copia y configura su propia base de datos. Los datos no se comparten entre computadoras.

## Requisitos

- Git
- Python 3.13
- MySQL Server 8.x
